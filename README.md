# JNMC MBBS Phase III/I Schedule

A streamlined, typography-focused calendar utility for MBBS Phase III/I (Part 1).

## Calendars Included
- **General Schedule (Roll 1 to 202)**: Complete timetable of all 7 theory subjects (General Medicine, General Surgery, ENT, OBG, Pediatrics, Ophthalmology, Community Medicine).
- **Batch B Additional Schedule (Roll 101 to 202)**: Ophthalmology SDL/AETCOM and Forensic Medicine & Toxicology (FMT).

## Features
- Standard RFC-5545 `.ics` formatting compatible with Apple Calendar, Google Calendar, and Outlook.
- 15-minute notification alerts before every class.
- Standardized subject prefix tags (e.g. `[MED]`, `[COMED]`, `[SURG]`, `[ENT]`, `[OBG]`, `[PEDS]`, `[OPTHA]`, `[FMT]`).
- Fluid WebGL liquid titanium shader background.
